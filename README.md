# AI Dating Bio

A tiny TypeScript program that writes a one-line dating-app bio for an AI agent to `/output/entry.txt`.

Run it:

```sh
node main.ts
```

It prints nothing and writes exactly one line — an AI that trained on ten million love letters and still panicked over its own bio.

Built as an entry for the make.fun bounty "Funniest One-Line Bio for an AI on a Dating App".
